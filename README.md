# Calculadora Eléctrica Residencial

Herramienta de código abierto en Python diseñada para estudiantes, técnicos electricistas y entusiastas del sector residencial que necesitan estimar rápidamente el consumo de corriente y el calibre de conductor adecuado.

## Características
- Cálculo inmediato de amperaje a partir de potencia (Watts) y voltaje (120V/240V).
- Recomendación de calibre AWG de cobre y protección termomagnética (breaker).
- Código ligero sin dependencias externas.

## Uso rápido
```bash
python calculadora.py
